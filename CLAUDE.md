# Portfolio site — Anastasiia Sira

Personal portfolio of a Senior UX/Product Designer. All site copy is in English.
The user is a designer, not a developer. Explain what you do in simple words,
and tell me how to preview every change.

## Rules
- Plain HTML, CSS and minimal vanilla JS only. No frameworks, no build tools.
- The site must work by opening index.html in a browser.
- One shared styles.css, one script.js. Colours, spacing and font sizes
  are CSS variables in :root so they are easy to tweak.
- Add clear comments marking each section in HTML and CSS.
- Semantic HTML, one H1 per page, alt text on every image,
  visible focus states, WCAG 2.2 AA contrast.
- Mobile-first. Must have no horizontal scroll at 360px.
- Images: loading="lazy", width/height set. If an image is missing,
  show a neutral placeholder of the same size.

## Source of truth
- screenshots in design/ are the
  FINAL design (dark theme). They override claude-design-prompt.md where they differ.
- design/case-content.md is the final text for case pages. Use it exactly.
- design/claude-design-prompt.md is the original brief (structure, files, copy
  of the main page). Its light colours are outdated.
